#  Rocket Launch Simulation Using OpenGL

A simple and interactive **2D Rocket Launch Simulation** built using **Python** and **OpenGL (PyOpenGL)**. This project demonstrates basic **computer graphics concepts** such as animation, transformations, keyboard interaction, and rendering in a space environment.

---

##  Project Overview

The **Rocket Launch Simulation** project is a simple computer graphics simulation where a rocket launches upward continuously in space. The user can move the rocket horizontally using keyboard arrow keys.

The project is developed using **Python OpenGL (PyOpenGL)** and demonstrates real-time graphics rendering and animation techniques.

This simulation includes:

- A moving rocket animation
- Keyboard interaction
- Space background with stars
- Smoke blending effect
- Smooth rendering using OpenGL

---

##  Features

###  Rocket Launch Animation
- The rocket continuously moves upward to simulate a launch effect.
- When the rocket reaches the top, it restarts from the bottom.

###  Rocket Movement Control
- Users can move the rocket:
  - **Left Arrow Key** → Move Left
  - **Right Arrow Key** → Move Right

###  Space Background
- Displays stars in the background to create a realistic space environment.

###  Smoke Effect
- Uses **OpenGL Alpha Blending** for smoke visualization.

###  Smooth Animation
- Uses **double buffering (`GLUT_DOUBLE`)** for smooth graphics rendering.

###  Computer Graphics Concepts Used
This project demonstrates:

- Bresenham Line Algorithm
- 2D Coordinate System
- Translation Transformation
- OpenGL Rendering
- Keyboard Event Handling
- Animation using Timer Function
- Alpha Blending
- Double Buffering

##  Requirements

Before running the project, make sure the following are installed:

### Software Requirements
- Python **3.x**
- OpenGL Supported Environment

### Python Libraries

Install required dependencies using:

```bash
pip install PyOpenGL PyOpenGL_accelerate
```


---


## ▶️ How to Run the Project

### Step 1: Clone the Repository

Open terminal or command prompt and run:

```bash
git clone https://github.com/kheya398/Rocket-Launch-Simulation-Using-OpenGL.git
```

---

### Step 2: Navigate to Project Folder

```bash
cd rocket-launch-simulation
```

---

### Step 3: Install Dependencies

```bash
pip install PyOpenGL PyOpenGL_accelerate
```

---

### Step 4: Run the Project

Run the Python file:

```bash
python main.py
```
